4. eBayに貼る

  1. 出品画面のDESCRIPTIONで、「Custom template」→「Create template」を押す
  2. Template nameに名前を入れる(20字まで)
  3. 「Show HTML Code」にチェックを入れる
  4. コピーしたコードを貼る
  5. Saveを押す

次の出品からは、「Custom template」でテンプレを選ぶだけです。テンプレは10個まで保存できます。

書きかえるところ

[ ]で囲んだところだけ、自分の店に合わせて書きかえてください。

  • [B] と、そのあとの1文: 品ごとのランクと、気になる点
  • [Main unit only.]: 付属品
  • [3] business days: 発送までの日数
  • [4] days / [30] days / [24] hours: 支払い・返品・返信の日数

文章をアレンジしたいとき

いちばんかんたんなのは、「Show HTML Code」のチェックを外すことです。コードではなく、できあがりの見た目のまま文字を打ちかえられます。

  • 1文は10語まで。長くなったら2つに切る
  • いらない見出しは、見出しと下の文をまとめて消していい
  • 関税の1文(Import duties, 〜)は、言い回しを変えない
  • 店の外のリンク、メールアドレス、電話番号は書かない

英語に自信がなければ、AIにこう頼みます。「eBayの説明文に入れる英語を作って。1文10語以内。中学生でも読める単語で。内容は『箱に少しへこみがあります。中身は未使用です』」
