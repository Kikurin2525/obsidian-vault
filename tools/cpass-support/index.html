02

入れ方

はじめの1回・2分

Chromeに「パッケージ化されていない拡張機能」として読み込みます。ストアからは入れません。

  1. zipを開いて extension フォルダを保存デスクトップなど、あとで消さない場所に。このフォルダがそのまま拡張になります。
  2. Chromeのアドレス欄に chrome://extensions拡張機能の管理画面が開きます。
  3. 右上の「デベロッパーモード」をオンオンにすると、左上にボタンが3つ出ます。
  4. 「パッケージ化されていない拡張機能を読み込む」→ extension を選ぶ一覧に「CPaSSサポート(非公式)」が出たら完了です。
  5. ツールバーのパズルマーク → 📌でピン留めアイコンを押すと、使い方と「覚えた品物を忘れる」ボタンが出ます(右の画面)。
新しい版にするとき:extension フォルダを入れかえ → 拡張機能の画面で 🔄 → CPaSSのページも読み込み直す
03

使い方

ふだんはこれだけ

ボタンを2回押して、最後にCPaSSの「保存する」を押すだけです。

  1. 発送手続き
  2. 編集
  3. CPaSSサポート
  4. この内容で入れる
  5. 保存するご自身で
1

「編集」を開いて、ボタンを押す

CPaSSの注文で「発送手続き」→「編集」を開きます。詳細画面の品物ごとに、「告知のための商品名(英語)」の見出しの右へ青い「CPaSSサポート」ボタンが出ます。品物が2つ以上ある荷物は、品物ごとに押してください。

2

中身を確かめて「この内容で入れる」

ボタンの下に、eBayの4色の線が付いたパネルが開きます。品物の種類・英語の商品名・HSコードが自動で用意され、番号は公式の表で確かめた結果が出ます。よければ青い「この内容で入れる」を押すだけです。

パネルの見方意味
届け先国旗から読んだ国と、確かめに使う表
品物自動で見分けた種類。ちがうときは一覧から選び直せます
商品名(英語)税関に出す名前。そのまま書きかえられます
HSコード 公式で確認ずみ届け先の国の公式の表で確かめた番号
見分け番号が細かく分かれる品物で、どの形として入れたか(タイトルの言葉/いちばんよくある形)
3

欄に入ったのを見て「保存する」

商品名とHSコードがCPaSSの欄に入り、パネルは閉じます。CPaSSの「保存する」は自動では押しません。目で確かめてから押してください。

「保存する」はご自身で
品物の種類がちがうとき

パネルの「品物」の一覧から正しい種類を選ぶと、番号と商品名がその種類に変わります。選び直した種類は、同じ品物(アイテム番号・SKU)で次から自動で使われます。

米国・EU・英国以外の国

国際共通の6桁を入れます。CPaSSから国の10桁を求められたときは、HSコード欄の横の🧭(CPaSSの番号さがし)で選び直してください。

答え表にない品物

黄色の表示が出たら、公式の表を英語で探して選びます。

  1. 品物を英語で入れて「公式の表で探す」(例: whetstone)
  2. 候補からいちばん合う行を押す(公式の表で確かめてから使います)
  3. 商品名も「何か」が分かる英語に直して「この内容で入れる」
探している途中の画面を見る
04

困ったとき

⛔ が出たときは、まちがった番号を入れないために止まっています。下の表のとおりにしてください。

表示やること
HSコードの欄に入りませんでした番号を押すとコピーされます。CPaSSのHSコード欄に貼ってください
この品物の欄を1つに決められませんでした別の品物に入れないための安全装置です。詳細画面を閉じて開き直してください
届け先の国が読めません入れずに、CPaSSの🧭で番号を選んでください
商品名が受け付けられない書き方「何か・素材や機能」まで英語で。例: Used digital camera, Canon EOS 5D
公式の表に今つながりません少し待って開き直す。急ぐときは「番号を確かめずに入れる」(答え表の番号は作成時に公式で確認ずみ)
ボタンが出ない拡張機能の画面でオンになっているか確認 → CPaSSのページを読み込み直す
05

大事なこと

申告の内容と責任は、出品者ご本人にあります。

この拡張は入力の手伝いです。番号が細かく分かれる品物は「いちばんよくある形」で入ることがあります。高額品や迷う品は、入れる前に税関・通関業者にご確認ください。

非公式eBay・CPaSSとは関係のない、個人が作ったツールです
読むもの品物のタイトル・アイテム番号・eBayカテゴリの番号・届け先の国旗だけ。買い手の名前や住所は読みません
送るもの番号を確かめるため、HSコードと品物の言葉だけを公式の表(USITC・英国政府)へ
保存覚えた品物の種類は、お使いのChromeの中だけ(拡張のアイコンから消せます)
押さないもの「保存する」・ラベル作成・発送のボタン
