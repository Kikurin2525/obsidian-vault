どの色を変える？

元の色 → 変更先。主な有彩色をメイン、異なる色相の強い色をアクセントに仮割当てします。淡い暖色は保留します。色の特徴による推定なので、対応表で直せます。同じ色は同時に変わるため、必要なら範囲を囲んでください。

白・黒・グレーを変更するには、チェックを外して変更先を選びます。

画像全体を変更

色を置き換えるシミュレーションです。人物・肌・写真の領域や文字の意味は自動判別しません。サイトのHTML自体は変更しません。長辺1600px・150万画素を超える画像は、縮小してプレビュー・保存します。

この画像の読みやすさは自動検査していません。下の検査結果は「見本で試す」の色指定に対するものです。変更後のPNGと元画像も制作AIへ添付してください。
