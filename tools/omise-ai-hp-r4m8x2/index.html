先行特典

AIで、お店のホームページを作る手順書

参考にしたいホームページのURLかスクショを、お店の写真と情報と一緒にAIに渡すだけ。デザインの知識もプログラミングもいりません。実際に作ったダンススタジオの例を、渡したものから全部見せます。

  • 実際に作った例
  • 直し方
  • 気をつけること
WHAT

この手順書で、できること

1

1日で、お店のHPができる

好きなホームページを「この雰囲気で」と渡すだけ。色・文字・余白・並びを、AIがまねして組み立てます。

2

どんなお店でも使える

サロン・教室・整体・飲食・レンタルスペース。業種に合う参考ページを選べば、そのお店らしくなります。

3

HPが、AIの教科書になる

HPに書いたお店の情報は、そのまま「お客さま対応をAIに任せる」ときのデータになります。

PREPARE

準備するもの(4つ)

① AI(ChatGPT か Claude)

無料プランでも試せます(画像の添付の回数などに上限があります)。Claude Code や Codex を使っている人は、フォルダを渡すだけでファイルまで作ってくれます。

② 参考にしたいHPのURLかスクショ

「こんな雰囲気にしたい」と思うページを1つ。同じ業種でなくてもかまいません。URLを読めないAIもあるので、スクショ(ページ全体)があると確実です。

③ お店の写真

スマホで撮ったものでOK。いちばん見せたい1枚(お店の全体や看板商品)と、ほかに3〜6枚。明るい時間に、横向きで。

④ お店の情報のメモ

名前・場所・営業時間・料金・選ばれる理由・よくある質問。下のひな形をコピーして、うめるだけです。

STEPS

5つの手順

  1. 参考にしたいホームページを1つ選ぶ

    「こうなりたい」と思うお店のページを探して、スクショを撮ります。パソコンなら、ページ全体のスクショがおすすめです。

    選び方のコツ: 同じ業種のいちばん人気のお店か、自分の好きなブランドのページ。色が2〜3色で、写真が大きいページほど、AIがまねしやすいです。

  3. 写真をそろえる

    写真のファイル名を、英字の短い名前にしておくと、AIが迷いません(例: hero.jpg・menu1.jpg)。いちばん大きく出したい1枚を hero にします。

  4. 指示文をコピーして、AIに渡す

    参考ページのスクショと写真を添付して、下の指示文と、②のメモを貼りつけて送ります。

    あなたは、お店のホームページを作るプロのWebデザイナーです。
添付の「参考ページ」のスクショのような雰囲気で、わたしのお店のホームページを1ページで作ってください。

【参考にしてほしいところ】
- 色の使い方(参考ページの色を中心に。差し色は1色だけ)
- 文字の大きさ・太さと、余白のとり方
- ページの並び(大きな写真とひとこと → 予約ボタン → 選ばれる理由 → 料金 → メニュー・設備 → アクセス → よくある質問 → 予約ボタン)

【まねしないところ】
- 参考ページの文章・ロゴ・写真は使わない。文章は、下の「お店の情報」から書く

【お店の情報】
(ここに、お店の情報のメモを貼る)

【写真】
添付のとおり。hero をいちばん上に大きく。ほかは、選ばれる理由・メニュー・アクセスのところに

【作り方】
- HTMLとCSSで、index.html の1ファイルに。写真は images/ フォルダのファイル名で読みこむ
- できた index.html は、ダウンロードできる形で出して
- スマホで見る人が多いので、スマホで見やすく。パソコンでも間のびしないように
- 予約ボタンは、ページの上と下に。スマホでは画面の下に固定
- お店の情報に書いていないこと(数字・実績・口コミなど)は作らない。足りないところは、最後に一覧で教えて
    ChatGPT・Claude の画面で作るとき: 返ってきた index.html をダウンロードして、写真を入れた images フォルダと同じ場所に置きます。index.html をダブルクリックすると、ブラウザでそのまま見られます。

  5. 見て、直して、公開する

    スマホとパソコンの両方で見て、気になるところを「ここをこう直して」と伝えます(直し方の例)。できたら、無料で使えるサイト公開のサービス(例: Netlify、Cloudflare Pages)に、フォルダごと載せて公開します。

    公開の費用: 料金や手順は変わることがあるので、各サービスの公式ページで確かめてください。お店の名前の独自ドメインを付けるときは、別に年間の費用がかかります。

FIX

直すときの伝え方(例)

1回でぴったりにはなりません。気になるところを、1つずつ短く伝えるのがコツです。

  • 「いちばん上の写真を、もっと明るく見えるように。文字は写真の左下に」
  • 「料金を、大きな数字のカードで3つ並べて」
  • 「スマホで見たとき、文字が小さいので少し大きく」
  • 「予約ボタンの色を、参考ページのボタンと同じにして」
  • 「よくある質問を、押すと開く形にして」
  • 「全体の文章を、もう少しやさしい言葉に」
CARE

気をつけること

  • 参考にするのは雰囲気だけ。ほかのお店の文章・写真・ロゴは使いません。指示文にも「まねしないところ」を入れています。
  • AIが書いた中身は、必ず自分で読む。料金・時間・住所など、書いていない数字をAIが足すことがあります。
  • 住所の出し方を決める。人がいないお店は、丁目までにして「正確な住所は予約の確定後に」とする方法もあります。
  • お客さまの個人情報は渡さない。HPづくりに、お客さまの名前や連絡先はいりません。

HPができたら、次はお客さま対応

HPに書いたお店の情報は、そのまま「お客さま対応をAIに任せる」ときのデータになります。電話・メール・予約サイト・LINEのお客さま対応を、AIに任せる全手順とツールを1冊にまとめました。
