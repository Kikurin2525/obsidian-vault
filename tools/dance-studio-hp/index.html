      3ダウンロード

      写真も埋め込んだHTML1ファイル。ファイル名は index.html にしてあります。

      4公開のしかた(無料)

      1. Netlify Drop(いちばん簡単): app.netlify.com/drop を開き、ダウンロードした index.html を入れたフォルダをドラッグ&ドロップ。数十秒でURLが出ます。無料アカウントを作ると、あとから差し替え・独自ドメインの設定ができます。
      2. Googleビジネスプロフィールに登録し、「ウェブサイト」欄にそのURLを入れる。Googleマップの店舗カードに「ウェブサイト」ボタンが出ます。
      3. 予約サイトのプロフィール・InstagramのプロフィールにもURLを貼る。
      4. 独自ドメイン(例: studio-xxx.com、年1,500円前後)は「店名で検索されるようになってから」で十分。先に公開してください。
      直したいときは、このページに戻って入力を直し、もう一度ダウンロード→Netlifyで差し替え、でOK。入力はこのブラウザに残っています(「入力のバックアップ」も保存しておくと、別の端末やブラウザを消したときも復元できます)。

      5入力のバックアップ

      入力内容と写真はこのブラウザ(localStorage)にだけ保存され、外部には送信されません。生成されるHTMLも外部サービスを使いません(Googleマップの埋め込みを入れた場合のみ、地図部分はGoogleから読み込まれます)。
