作業の一覧(7つの型)

型ごとに「こんなことができます → 例えば → あなたなら → 任せ方」の順です。札の意味は、こうです。

  • 自動毎日・毎週など、勝手に回る
  • 下書きAIが作って、自分で見て送る
  • 依頼チャットで頼んだときに動く
  • 道具AIに作ってもらったアプリ・拡張を使う

ぼくの店(レンタルスペースとネットのお店)の例です。店の名前や商品は伏せて、どの商売でも通じる言い方にしています。

1お客さま対応と予約

0 / 6

お客さまからの連絡を、AIが1か所に集めて、返信の下書きまで作ってくれます。

例えばぼくの店では、予約サイトやメールに来るメッセージを、AIが1つの受信箱に集めます。返事が要るものには、返信案をつけて見せてくれます。

あなたなら教室の体験の申し込み、美容室の予約の変更、ネットショップの「いつ届きますか?」

任せ方B(下書きまで)。判断の要らない返事は自動で送る

2お金の請求と支払い

0 / 5

「請求→入金の確認→催促」の決まった流れを、AIに任せられます。

例えばぼくの店では、予約のキャンセルが入ると、AIがキャンセル料を計算して、支払いのリンクを送ります。期限が切れたら、送り直すところまで自動です。

あなたなら月謝の請求と未払いの確認、外注さんへの支払いの明細、帳簿づけ

任せ方A(全自動)。返金と振込は、ぼくが確かめてから

3数字の集計と報告

0 / 6

売上や予約の数字を自分で集めなくても、AIがまとめて届けてくれます。

例えばぼくの店では、店ごとの見込みの売上と利益を、いつでもダッシュボードで見られます。ネットのお店の利益も、毎朝レポートで届きます。

あなたなら今月の売上が目標まであといくらか、どのメニューが売れているか、先週の予約は何件か

任せ方A(全自動)

4見張りと点検

0 / 5

「気づいたときには手遅れ」になりがちなことを、AIが見張ってくれます。

例えばぼくのネットのお店では、仕入れ先で商品が売り切れたら、AIが在庫を0にします。販売ページの価格の表示がずれていたら、朝に知らせが来ます。

あなたなら在庫切れ、口コミの低い評価、近くのお店の値下げ、利用しているサービスの規約の変更

任せ方A(全自動)。おかしいときだけ知らせが来る

5価格と集客の調整

0 / 6

「ここまでなら下げていい」を決めておけば、価格や広告の見直しを、AIが毎日やってくれます。

例えばぼくのネットのお店では、競合に合わせて値段を直し、利益の下限まで来たら止めます。値下げ交渉を「受ける/断る」金額も、毎日合わせ直しています。

あなたならすいている時間の割引、季節ごとの価格、広告の予算の配分

任せ方A(全自動)。下限の決まりは、自分で決める

6商品と発信をつくる

0 / 6

話した言葉や、手もとの写真・データから、AIが記事や商品の形にしてくれます。

例えばぼくは、散歩しながら録音した話を、AIに文字にしてもらって、ブログの下書きにしています。清書したら、図解をつけて、いくつかの媒体に出すところまで進めてくれます。

あなたならお店のブログ、商品の説明、インスタの投稿文、お客さま向けの案内やマニュアル

任せ方C→B(頼んで、下書きを見てOK)

7段取りと調べもの

0 / 5

頭の中のやることと調べものを、AIの秘書に預けられます。

例えばぼくは、外出先からスマホで頼むと、家のパソコンでAIが作業して、返事をくれるようにしています。物件のURLを渡せば、◎○△✕で判定もしてくれます。

あなたなら新しいお店の候補地の下調べ、仕入れ先のくらべ方、外注さんへの連絡文

任せ方C(頼んだときに動く)

任せ方の3段階

段階自分がやること例
C 頼んだときに動くチャットで頼む予約の変更・物件の判定・ホームページの更新
B 下書きまで見て「送る」「OK」を押す返信案・請求のメール・投稿の下書き
A 全自動結果を見る(おかしいときに知らせが来る)在庫の同期・キャンセル料の請求・売上の集計

はじめはCから。同じ頼みごとが3回続いたらB、Bで直すところがなくなったらA、の順に上げていくと、無理なく任せる作業がふえていきます。

そのまま使える指示文7本

1本目で任せる作業を選び、2〜6本目で、任せたあとにつまずきやすい所を先に防ぎます。7本目は、任せて空いた時間で、あなたの経験を形にするときの1本です。

1毎日の作業から、任せられるものを3つ選ぶ

何から任せるか迷ったら、ここから。上の一覧で☑を付けた作業は、この指示文に自動で入ります。

このページの「AIに任せている作業の一覧」を読んで。
https://rental-space.net/tokuten/ai-tasks-511153f8/

わたしのふだんの作業は、こうです。
【ここに、ふだんの作業を箇条書きで。例: 予約の連絡に返事をする/月末に売上を表にまとめる】

この中から、AIに任せられそうなものを3つ選んで、7つの型のどれに当たるかと、任せ方(A 全自動/B 下書きまで/C 頼んだときに動く)を表にして。
手間がいちばんへるものから順に。それぞれ、はじめの1回でAIに渡すものも書いて。

2名前や連絡先を、伏せてから読ませる

お客さまの連絡をAIに読ませるときは、まずこの形で。返信の下書きは作れます。

このメッセージを読んで、返信の下書きを作って。
読む前に、名前・メールアドレス・電話番号・住所は【お名前】【メール】【電話】【住所】に書きかえて。
下書きにも、書きかえたままの形で入れて。宛先と名前は、わたしが送るときに入れます。

【ここにメッセージを貼る】

つまずき集 No.107 から

3数字の出どころを、1つのファイルにする

文章や報告のたびに数字がずれるのを防ぎます。

【売上の記録のファイル名】を読んで、【先月】の売上・件数・内訳を出して。
出した数字を「数字の正本.md」という1つのファイルに表で書いて、出どころ(どのファイルの、どの期間か)も書いて。
これから文章や報告を書くときは、数字はこの正本からとって、計算し直さないで。

つまずき集 No.17 から

4メモにない事実や数字を、足させない

AIは、それっぽい一文を足すことがあります。足したところを見えるようにします。

このメモを、【お知らせ/投稿/商品の説明】の文に書きなおして。
メモにない事実や数字は足さないで。足したところがあれば、文のあとに一覧で見せて。

【ここにメモを貼る】

つまずき集 No.63 から

5「できました」を、確かめてから受け取る

「できました」は、確かめた結果ではありません。照合してから受け取ります。

作業が終わったら、「できました」と言う前に、できあがったもの(ページ・ファイル・送った先)を開いて、頼んだ中身と1つずつくらべて。
くらべた結果を ✅/❌ の表で見せて。❌ があるうちは、できたと言わないで直して。
数字は最後に、わたしが目で見ます。

つまずき集 No.45・34 から

6任せた仕組みの結果を、毎朝1通にまとめる

任せる作業がふえるほど、止まっても気づきにくくなります。結果がとどく形にします。

わたしがAIに任せている、毎日・毎週動く作業を全部書き出して、1つの台帳(表)にして。
列は、名前・動く時刻・結果が残る場所・最後にうまくいった日時。
そのうえで、毎朝その結果を集めて、失敗と止まっているものを上にした1通の日報にするしくみの案を見せて。作るのは、わたしがOKしてから。

つまずき集 No.119 から

7あなたの経験から、作って売れるネタを選ぶ

任せて空いた時間で、あなたの経験を教材にするときの、はじめの1本です。

わたしが毎日やっていること・得意なことの候補は、【候補1】【候補2】【候補3】です。
話したいかどうかではなく、知りたい人の数でくらべたい。
それぞれ、知りたい人がどのくらいいそうか、調べた根拠といっしょに表にして。
AIは手段として使う前提で、「AIの使い方そのもの」が中身になっている候補には印を付けて。

正直に書いておくこと

  • ぼくの店の例です。同じ結果になることを約束するものではありません。
  • AIをどこまで使ってよいかは、サービスごとに規約がちがいます。ぼくは多くの作業をAIに任せていますが、どこまで任せるかは、規約を確かめたうえで、ご自身の責任で決めてください。任せない作業は、指示文を「手順を書き出して」に変えれば、自分で進める手順書になります。
  • eBay(海外向けのネットのお店)は、eBayに書面で確かめた範囲で使っています(2026年10月): 公式のAPIを通してAIに出品や価格の更新をさせるのはOK/AIにブラウザでeBayの画面を開かせるのはNG/買い手の個人情報は、本文の中にあるものも含めてAIに渡さない。
  • お客さまの名前や連絡先は、伏せてからAIに渡してください(指示文2)。
  • 料金・規約・画面の名前は、2026年10月時点です。使う前に、公式のページで確かめてください。
