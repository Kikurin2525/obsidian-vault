【eBay輸出】関税のすべて（チェックガイド付き）

2026.11.02

eBayで売れているのに、最後に残るお金が少ない。

そんなモヤモヤはありませんか？

  • 売上は伸びているのに、最終的な利益が思ったより少ない
  • 1件ずつ見ると利益が出ているのに、口座にはそれほど残らない
  • 少したってから、CPaSSの請求がとどいて金額に驚く

思い当たるなら、原因は関税かもしれません。

関税は、売れたその日には金額が決まりきりません。

ラベルを出すときは「推定」で引かれて、2〜3週間後の「精算」で差額が動きます。

なので、売れた日の計算では利益が出ていても、あとから減ることがあります。

とくに気をつけたいのは、いろいろなジャンルを出しているセラーです。

1つのジャンルにしぼった専門店なら、自分の品の関税が何%かは、すぐ分かります。

でも、品目ごとに率がちがうのに、全部に同じ率をかけて値段を決めていると、あとから思ったより請求されて、手残りがなくなります。

だから、いちど関税を見直しておきましょう。

見るのは、この5つだけです。

  1. 誰が払うか → 送り先の国で決まる
  2. 何%か → HSコード(関税の分類番号)と原産国で決まる
  3. いつ決まるか → ラベルのときは「推定」、2〜3週間後に「精算」
  4. 関税のほかに → 手数料がかかる
  5. 値段への入れ方 → 品目ごとの率で入れる

5つを押さえれば、関税はこわくありません。

この記事では、順番に、公式の発表をもとに書きます🐹

思い当たる方は、この記事をそのままAIに渡して、あなたのストアの関税を総点検してもらうのがおすすめです。

AIで実行するチェックガイド(プロンプトあり)は、記事の後半にあります。

この記事を書いた人

この記事は、アメリカ宛てをすべて関税込み(DDP)で送り、お客さんに追加の請求なしで届けてきたチャムが書いています。

関税の請求明細は、1件ずつ品目ごとに突き合わせています。

1. 誰が払うか → 送り先の国で決まる

送り先送り方関税・税を払う人
アメリカDDP(関税込み)セラー
EU・€150以下DDP(10月から必須)セラー
イギリス・£135以下eBayが購入時にVATを集める買い手
オーストラリア・A$1,000以下eBayが購入時にGSTを集める買い手
それ以外DDU(受け取り時に払う)買い手

関税をセラーが先に払う送り方を、DDPといいます。

買い手が受け取るときに払う送り方は、DDUです。

アメリカは、2025年に免税枠(デミニミス)がなくなりました。

いまは、安い品にも関税がかかります。

SpeedPAKでアメリカに送るときは、セラーが関税を先に払うDDPです。

EUは、2026年10月1日から、送料を除いて€150以下の品はDDPが必須になりました。

DDUで送って届かなかったときは、セラーの負けになり、消せないディフェクトが付きます。

EU向けDDP、当日に直した4か所2026年10月1日、EU向け€150以下のDDP必須化の当日に、eBayが挙げる3つ(値段・商品説明・配送ポリシー)を点検。さらに、梱包マニュアルと返信AIに…rental-space.net

イギリスとオーストラリアは、少額の品なら、eBayが買い手から税を集めて納めます。

セラーがやることはありません。

それ以外の国は、買い手が受け取るときに払うのが基本です。

商品説明には「アメリカは関税込み」「それ以外は受け取り時に関税がかかる場合がある」と、国で分けて書いておきます。

2. 何%か → HSコードと原産国で決まる

品目の例日本製で払う関税(売値に対して)
おもちゃ・ゲーム・PC・多くの機械12.5%
化粧品・香水・宝飾品12.5%
衣類12〜32%
靴12.5〜48%
本・レコード・写真・ポスター多くは0%
鉄・アルミ・銅を多く含む品25%以上
車の部品15〜25%

アメリカの関税は、2つの関税を足したものです。

  1. ふだんの関税: 前からある関税。品目ごとに率が決まっている
  2. 上乗せの関税: 2026年7月24日から始まった関税(Section 301)

ふだんの関税は、品目でかなりちがいます。

おもちゃやゲーム、PC、多くの機械は0%。

衣類は12〜32%、靴は3〜48%です。

上乗せの関税は、日本製なら「2つ合わせて12.5%」になるように足されます。

ふだんの関税が0%の品は、12.5%が足されます。

ふだんの関税が12.5%以上の品(衣類など)は、何も足されません。

例えば、売値1万円のおもちゃなら、ふだんの関税0%+上乗せ12.5%で、関税は1,250円です。

売値1万円の綿のTシャツなら、ふだんの関税16.5%だけで、関税は1,650円です。

つまり、日本製の多くの品は、売値の12.5%と覚えておけば、だいたい合っています。

ただし、例外が3つあります。

  1. 本・レコード・写真・ポスターなどの「情報の品」は、上乗せの関税がかかりません
  2. 鉄・アルミ・銅を重さで15%以上含む品は、別の上乗せ(Section 232)になります。金物や工具などは25%、鋼材などの素材は50%です
  3. 車の部品も、別の上乗せ(Section 232)になります。日本製は、公式の決まりでは合計15%です

▼HSコードと、ふだんの関税を調べるところ(USITC)

Harmonized Tariff Schedulehts.usitc.gov

原産国も、率を変えます。

「どこで作られたか」が原産国で、「どこから送ったか」ではありません。

日本で買った品でも、中国で作られていれば、中国の率になります。

例えば、CPaSSの推定の率は、日本製が12.5%、中国製は30%です。

3. いつ決まるか → ラベルのときは「推定」、あとで「精算」

SpeedPAKでアメリカに送ると、関税は2回、請求に出てきます。

  1. ラベルを作ったとき: 「推定関税」
  2. 2〜3週間後: 「関税」(推定は払い戻されて、実際の額に入れかわる)

ここで知っておきたいのが、推定は原産国だけで決まる一律の率だということです。

CPaSSのお知らせの表には、日本製は12.5%、と原産国ごとの率しかありません。

HSコードは見ていません。

なので、12.5%ではない品は、精算で額が変わります。

衣類、金属を多く含む品、車の部品などは、推定より実際が高くなりやすい品です。

差額は、あとから追加で請求されます。

いろいろなジャンルを出しているセラーほど、こうした品がまざりやすく、気づいたときには手残りが減っています。

ラベルを作ったときの金額で利益を計算していると、あとからずれます。

精算の明細は、CPaSSのセラーポータル(SpeedPAKの管理画面)の「料金を支払う」から、請求ごとにダウンロードできます。

「推定関税及び税金料金」がマイナスで戻され、「関税」が足されていれば、それが確定の額です。

月に1回は、推定と精算を比べてください。

4. 関税のほかに → 手数料がかかる

手数料かかる国いくら
関税処理手数料アメリカ・EU関税の約2.1%
現地税金元払い請求手数料アメリカ(DHL)1件¥935
UHF(EU取扱手数料)EU1件€2(約370円)
EUの関税EU・€150以下1件€3(約555円)

関税のほかにも、小さな手数料がつきます。

例えば、ぼくのストアの明細では、DHLで送ったアメリカ宛ては、精算のたびに「現地税金元払い請求手数料」が935円ついていました。

FedExでは、この手数料はありませんでした。

安い品ほど、この935円の重さが効いてきます。

EUのUHFは、2026年11月から始まった手数料です。

荷物1つではなく、HSコード1つごとにかかり、届かなくても返金されません。

5. 値段への入れ方 → 品目ごとの率で入れる

アメリカ宛てがDDPなら、関税は値段の中に入れておくしかありません。

入れ方は、この式です。

関税の見込み = 売値 × 品目の率 + 手数料

全部の商品に同じ率(例えば15%)をかけると、12.5%の品は少し高すぎ、衣類や金属の品は足りなくなります。

専門店なら、率は1つか2つで済みます。

いろいろなジャンルを出しているなら、少なくとも3つに分けて値段を決めてください。

  • 12.5%の品(おもちゃ・ゲーム・機械・化粧品など)
  • 12.5%より高い品(衣類・靴の一部)
  • 別の上乗せの品(金属を多く含む品・車の部品)

品目ごとに、こう確かめておくと、ずれが小さくなります。

  1. 売れ筋の品のHSコードを、USITCで確かめる
  2. ふだんの関税が12.5%より高いかを見る
  3. 金属を多く含む品・車の部品かを見る
  4. 原産国を、作られた国で正しく書く
  5. 精算の明細で、見込みと実際を比べる

HSコードは、FedEx・DHLで送るときは、セラーが自分で入力します。

関税は、入力したHSコードで決まります。

オレンジコネックスは、税関が決めた分類や関税額への異議は受け付けない、と案内しています。

まちがえたHSコードで払った関税は、原則として戻ってこないと考えてください。

例えば、ぼくのストアでは、関税の見込みをAIが品目ごとに計算しています。

精算の明細を取り込むたびに、見込みとずれた注文があれば知らせてもらいます。

AIの使い方は、各サービスの規約を確かめたうえで、ご自身の責任で決めてください。

AIに任せない人は、月に1回、明細をスプレッドシートに貼って、品目ごとの率を出すだけでも十分です。

AIに関税の総点検をしてもらうチェックガイド

この記事と、あなたのストアのデータをAIに渡すと、5つの見方で関税を点検してくれます。

渡すものは、この3つです。むずかしい準備はいりません。

渡すもの用意のしかた
この記事本文をコピーする
出品中の商品の一覧Seller Hubの「レポート」から、表のファイル(CSV)でダウンロード
CPaSSの精算の明細CPaSSの「料金を支払う」から、直近1〜3か月分をダウンロード

出品中の一覧は、Seller Hubの「レポート」→「ダウンロード」→「レポートをダウンロード」で、出品(Listings)の「すべての出品中の商品」を選ぶと出せます。

出品が多い方は、売れ筋の20品だけを残して渡しても大丈夫です。

ストアのURLだけを渡す方法は、おすすめしません。

eBayの規約では、許可なくプログラムでページを読み取ることが禁止されています。

それに、AIが読めるのは最初の数十件くらいで、原産国も出品ページには出ていないことが多いからです。

明細や一覧に、買い手の名前や住所が入っているときは、その列を消してから渡してください。

あなたは、eBay輸出の関税にくわしいアドバイザーです。
下に貼る記事の5つの見方で、わたしのストアの関税を総点検してください。

【渡すもの】
・記事の本文
・出品中の商品の一覧(Seller Hubのレポート)
・CPaSSの精算の明細(直近1〜3か月)

【やってほしいこと】
1. 商品名から品目を読み取り、「12.5%の品」「12.5%より高い品」「別の上乗せの品(金属を多く含む品・車の部品)」の3つに分けて、アメリカ宛ての関税の率の見込みを出す
2. それぞれのHSコードの候補を書く。自信がないものは「要確認」として、USITCで調べる番号を書く
3. 精算の明細で、推定関税と確定の関税の差が大きい注文を、差が大きい順に出す
4. 関税と手数料が売値の何%になるかを出し、高い品から順に出す
5. 値段の決め方をどう分けるとよいかを、3つまでで提案する

【守ること】
・原産国が書いていない品は日本製として計算し、「要確認」と書く
・関税の率は、公式の発表(CBP・USITC・配送会社のお知らせ)で確かめられたものだけを言い切る
・分からないところは推測で埋めず、「要確認」と書く
・答えは表にして、最後に「次にやること」を3つ書く

AIの答えの率は、最後にUSITCで10桁のHSコードを引いて確かめてください。

とくに、衣類・靴・金属を多く含む品・車の部品は、品目でかなり率が変わります。

まとめ

eBay輸出の関税で見るのは、この5つでした。

  1. 誰が払うか → アメリカとEU€150以下はセラー(DDP)
  2. 何%か → 日本製の多くは売値の12.5%。衣類・金属・車の部品は別
  3. いつ決まるか → ラベルは推定、2〜3週間後に精算
  4. 手数料 → 関税処理・DHLの935円・EUのUHF
  5. 値段への入れ方 → 全部同じ率ではなく、品目ごとの率で
