プライバシーポリシー

アプリ「ゲームで学ぶレンスペ経営」(iOS版)およびWeb版(このサイトの /game/)における、個人情報のあつかいについて説明します。

1. 集めていない情報

このアプリは、氏名・メールアドレス・電話番号・住所・位置情報・連絡先・写真・カメラ・マイク・広告識別子(IDFA)を取得しません。アカウント登録もありません。ユーザーを追跡(トラッキング)することはなく、第三者の広告ネットワークにデータを渡すこともありません。

2. ゲームの進行データ

選んだジャンル・エリア・物件、資金や売上などの進行状況は、お使いの端末の中だけに保存されます(ブラウザのローカルストレージ)。当社のサーバーへ送信されることはありません。アプリを削除すると、この進行データも消えます。

3. 教材(アプリ内課金)を購入した場合

教材の購入は、AppleのApp内課金でおこなわれます。お支払い情報(クレジットカード番号など)はAppleが取り扱い、当社が受け取ることはありません。

購入した方だけが教材を開けるようにするため、当社のサーバー(Cloudflare)に次の情報だけを記録します。

記録するものAppleが発行する取引ID / 元の取引ID / 商品ID / 確認した日時 / 環境(本番かサンドボックスか)
記録しないもの氏名・メールアドレス・カード情報・端末の識別子・IPアドレスの保存
目的購入の確認と、教材を開くための一時リンク(15分間有効)の発行のみ
保存期間購入の権利を確認できる状態を保つため、購入の記録は保持します。削除のご希望は下記の連絡先へ

4. アクセス解析

Web版(rental-space.net/game/)では、どの画面まで遊ばれたかを知るためにGoogleアナリティクスを使用しています。個人を特定する情報、店舗名・地域の選択・セーブデータ・金額は送信していません。Web版の画面下「遊び方・データについて」からいつでも停止できます。

iOSアプリ版では、アクセス解析を使用していません。

5. お子さまの利用について

本アプリは13歳未満のお子さまを対象として設計・宣伝していません。お子さま向けに情報を集めることもありません。

6. 外部へのリンク

アプリ内から当社のWebサイト(教材の紹介ページなど)へ移動できる場合があります。移動先での情報のあつかいは、その移動先の方針によります。

7. 改定

内容を変更したときは、このページを更新します。
