2026.11.08

脱サラは、会社にいるうちに副業で始めて、副業の利益が給料の手取りに届いてから辞めると失敗しにくいです。

ぼくは37歳の会社員のときに、副業でレンタルスペースの1号店を出しました。

会社員のまま14店舗まで増やして、40歳で会社を辞めています。

辞めたとき、副業の利益は、給料の手取りとほぼ同じでした。

辞めてから困ったことは、正直ありません。

ストレスが、本当に大きくへりました。

先に、答えを5つ書いておきます。

  1. 辞めていい基準: 副業の利益が、給料の手取りに届いていること(ぼくは0.9〜1.1倍)
  2. 貯金: 一般には生活費の半年〜1年分。ぼくは結果として1年半〜2年分くらいあった
  3. 辞める前にやること: クレジットカードと住宅ローンは会社員のうちに。健康保険と年金の切りかえは期限がある
  4. 辞めた後の収入: レンスペの利益は、辞めた年を1として、2年後に約2.9倍
  5. 何をするか: 会社にいるうちに試せて、自分がいなくても回る仕事を選ぶ

この記事を書いた人

この記事は、会社員のときにレンタルスペースの1号店を出し、副業のまま14店舗まで増やしてから、40歳で脱サラしたきくりんが書いています。

いまは法人にして、レンタルスペース23店舗とeBay輸出、教育事業を、AIといっしょに1人で回しています。

脱サラとは?辞めたあと何をする人が多い?

脱サラとは、会社員を辞めて、自分で仕事を始めることです。

「脱サラリーマン」を短くした言葉です。

辞めたあとの進路は、大きく4つです。

進路例始めるお金
フリーランスデザイン・プログラミング・ライター小さい
お店を開く・フランチャイズに入る飲食・コインランドリー・学習塾大きい
会社をつくって事業をするネット販売・サービス業事業しだい
副業を本業にするレンタルスペース・eBay輸出・ブログ会社員のうちに払い終わる

ぼくは、4つ目の「副業を本業にする」でした。

いちばん失敗しにくいのも、この形だと思っています。

理由は、辞める前に「本当にお金が入るか」を確かめられるからです。

脱サラの現実: 数字で見る成功率

脱サラの現実は、「全員がうまくいくわけではない」です。

中小企業白書によると、起業から5年後に残っている会社は、約8割(81.7%)です。

ただし白書は、データベースに載っている会社だけで数えているので、実際より高めに出ている可能性がある、とも書いています。

裏を返すと、5年で約2割は残れていません。

ネットでは「5年で8割残る」「10年で1割も残らない」と、数字が記事によってばらばらです。

元の調べ方がちがう数字が、まぜて紹介されているためです。

数字を見るときは、白書など元の資料までたどると安心です。

うまくいかない理由は、だいたい次の3つです。

  1. 業種: 始めるお金が大きく、元が取れるまで長い仕事を選んだ
  2. お金: 生活費と、事業が軌道に乗るまでのお金が足りなかった
  3. お客さま: 開いてから集客を考えた

3つとも、会社にいるうちに副業で試すと、小さくできます。

辞めていい5つの基準

脱サラしていいかは、次の5つで決めます。

  1. 副業の利益が、給料の手取りに届いている
  2. 生活費の貯金が、半年〜1年分以上ある
  3. 会社員のうちに作るもの(カード・ローン)を作り終えた
  4. 自分がいなくても、事業が回る
  5. 家族が、安心してOKと言える

1. 副業の利益が、給料の手取りに届いている

いちばん大事なのは、これです。

ぼくが辞めたころ、レンタルスペースの月の利益は、会社の給料の手取りとほぼ同じでした。

月によって、手取りの0.9〜1.1倍です。

ぼくは、貯金の額より「毎月の収入が、会社の給料をこえること」を大事にしていました。

貯金はへっていくだけですが、毎月の収入は、辞めたあとも入り続けるからです。

例えば、手取りが月30万円の人なら、副業の利益が月30万円に届くのが目安です。

レンタルスペースなら、軌道に乗った部屋で月10万円前後なので、3部屋ほどです。

部屋の数の考え方は、副業の記事にまとめています。

ひとつ注意があります。

副業の利益は、税金や社会保険料を引く前の額です。

会社を辞めると、健康保険と年金は全額を自分で払うことになります。

だから、利益が手取りに「ぴったり届いた」くらいなら、次の貯金が大事になります。

2. 生活費の貯金が、半年〜1年分以上ある

よく言われる目安は、生活費の半年〜1年分です。

ぼくは、意識して貯めていたわけではありません。

ふり返ると、結果として1年半〜2年分くらいありました。

毎月の収入が給料に届いていれば、貯金は「もしものときの守り」です。

届いていないなら、貯金は「届くまでの時間」になります。

届いていない状態で辞めるなら、半年〜1年分では足りないこともあります。

3. 会社員のうちに作るもの(カード・ローン)を作り終えた

クレジットカードと住宅ローンは、会社員のほうが審査に通りやすいです。

ぼくは、どちらも会社員のうちに作りました。

くわしくは、「辞める前にやっておく5つ」に書きます。

4. 自分がいなくても、事業が回る

会社員のあいだは、本業の時間に副業はできません。

だから、副業の時点で「自分がいなくても回る仕組み」ができているはずです。

ぼくの場合、清掃は外注、電話はAIの電話番です。

これができていれば、辞めたあとの時間は、そのまま部屋を増やす時間になります。

5. 家族が、安心してOKと言える

会社をやめたい気持ちは、家族もずっと知っていました。

ふだんから、そう話していました。

それでも、気持ちだけでは家族は安心できません。

だからぼくは、会社員と並行して副業で始めて、形にしてから辞めました。

家族が安心して「いいよ」と言える状態をつくるためです。

脱サラは、1人の人生だけの話ではありません。

家族がいるなら、5つの中でここがいちばん大事かもしれません。

  2. 自分の時間を売る仕事か、仕組みが稼ぐ仕事か
  3. 在庫をかかえるか
  4. 人を雇う必要があるか
  5. 会社にいるうちに試せるか

1. クレジットカードは、会社員のうちに

ぼくは、辞める前にクレジットカードを作りました。

事業を始めてすぐは、決算の数字がまだないので、審査で不利になりやすいからです。

2. 住宅ローンも、会社員のうちに

ぼくは、家も会社員のうちに買っておきました。

住宅ローンの審査では、勤め先と勤続年数が見られます。

独立したあとは、事業の決算が何年分か必要になることが多いです。

審査の結果は、人と金融機関によってちがいます。

家を買う予定があるなら、辞める前に一度相談しておくと安心です。

3. 健康保険は、任意継続か国民健康保険か

会社を辞めると、会社の健康保険から外れます。

選べるのは、主に2つです。

  • 任意継続: 会社の健康保険に、2年間続けて入れる。保険料は、会社が払っていたぶんも自分で払うので、在職中の約2倍(上限あり)
  • 国民健康保険: 住んでいる市区町村の保険に入る。保険料は、前の年の所得で決まる

ぼくは、任意継続にしました。

どちらが安いかは、人によってちがいます。

協会けんぽ(または会社の健保組合)と市区町村の両方で、金額を出してもらって比べるのが確実です。

任意継続に入れるのは、辞めた日までに続けて2か月以上、会社の健康保険に入っていた人です。

申し出は、辞めた日の翌日から20日以内です(郵送は20日以内に届く必要があります)。

出典: 全国健康保険協会「任意継続の手続き」

任意継続｜給付と手続き｜協会けんぽkyoukaikenpo.or.jp

会社員の厚生年金から、国民年金に切りかえます。

届け出は、住んでいる市区町村の役所で、辞めた日の翌日から14日以内です。

令和8年度の国民年金の保険料は、月1万7,920円です。

30代・40代・50代の脱サラ

年代で変わるのは、貯金・信用・時間の3つです。

年代強み気をつけること
30代時間がある。失敗してもやり直しやすい貯金が少ないことが多い。副業で利益が届くまで待つ
40代貯金と会社員の信用がある。仕事の経験が長い家族・住宅ローン・教育費。家族が安心できる形が先
50代貯金と退職金。人脈体力。始めるお金の大きい仕事に、退職金をまとめて入れない
