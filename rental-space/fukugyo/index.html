レンタルスペースは副業に向いてる?3つの理由

レンタルスペースが副業に向いている理由は、3つです。

  1. お店にスタッフがいらない
  2. 会社員の信用が、物件を借りるときに武器になる
  3. 部屋を足すほど、収入が足し算で増える

お店にスタッフがいらない

予約はポータルサイトが受けてくれます。

ポータルサイトとは、たくさんのお店を集めて、お客さまが探して予約できるサイトのことです。

美容室ならホットペッパービューティー、飲食店なら食べログやぐるなび、旅行ならじゃらん。

レンタルスペースでは、スペースマーケットやインスタベースがこれにあたります。

自動でお客さまに利用方法のメッセージが届きます。

鍵は暗証番号で開け閉めでき、支払いもネットで終わります。

だから、あなたが店にいる必要がありません。

本業の時間とぶつかりにくい副業です。

会社員の信用が、物件を借りるときに武器になる

物件を借りるときは、審査があります。

会社員の安定した収入は、審査でそのまま信用になります。

「副業だから落とされるかも」という心配は不要です。

部屋が増えれば、収入が足し算で増える

1部屋で仕組みができると、2部屋目からは同じやり方を使えます。

時間を売る副業とちがって、部屋の数だけ収入が増えます。

副業で失敗しやすい5つ

副業で始める人が、つまずきやすい所は5つです。

  1. 音の確認をしないで借りる → 騒音で撤退
  2. 管理規約を見ないで借りる → 入居したその日に退去
  3. 特定の日だけ需要があるジャンルを選ぶ → 赤字の月が続く
  4. 価格設定を見直さない → 1年ずっと取りこぼす
  5. キャンセルの決まりを決めていない → 直前キャンセルで売上が消える

どれも、契約やオープンの「前」に防げるものです。

Q2. 平日は、1日何分くらいかかりますか?

オープンしたあとは、1日0〜数分です。

会社の就業規則しだいです。

副業の所得にかかる住民税は、確定申告で「自分で納付」を選べます。

ただ、扱いは市区町村によってちがうことがあるので、就業規則とあわせて、ご自身で確かめてください。

Q4. 確定申告は、いつから必要ですか?

給与を1か所からもらっている会社員は、副業の所得が年20万円をこえたら必要です。

所得は、売上から家賃や手数料などの経費を引いた額です。

Q5. 初期費用は、いくらからですか?

ぼくの23店舗でいちばん安かったのは、約27万円の小さな貸し会議室でした。

鏡と工事が要るダンススタジオは、約214万円でした。

Q6. 月にいくら残りますか?

軌道に乗った部屋で、ぼくの店の平均は月約10万円です。

開業から半年くらいは、月3万〜5.5万円ほどの時期が続きます。

Q7. 自宅の空き部屋でもできますか?

持ち家なら、大家さんの承諾はいりません。

分譲マンションなら、管理規約で事業での利用が禁止されていないか確かめてください。

ご近所への音や出入りの配慮も必要です。

Q8. 運営代行に全部任せてもいいですか?

任せられます。

ただ、ぼくの例では、利益は売上100あたり28から18にへりました。

本業がいそがしい時期だけ任せる使い方もあります。

Q9. 動いているお店を買う方法はありますか?

あります。

事業を売り買いするサイトで、運営中のレンタルスペースが売りに出ていることがあります。

買う前に、直近の月ごとの売上と、物件の契約の残りの期間を必ず確かめてください。

まとめ: 副業で始める人が押さえる5つ

レンタルスペースは、会社員の副業に向いています。

押さえることは、5つです。

  1. 時間: オープンしたあとは1日0〜数分。設営は休日と有給でまとめて
  2. お金: 初期費用は約27万〜214万円。最初の半年は利益が少ない
  3. 足し算: 1部屋=月10万円前後。5部屋持てば、平均年収をこえる
  4. 税金: 20万円をこえたら確定申告。住民税の納め方は自分で選べる
  5. 仕組み: 清掃は外注、電話と返事はAI。人がやるのは物件選びだけ
